# Panadería Trigal — Proyecto de equipo

Sitio web de 4 secciones desarrollado como práctica de control de versiones con Git y GitHub.

## Ver el sitio
`https://TU-USUARIO.github.io/proyecto-web/` (activar en Settings → Pages)

## Estructura
```
proyecto-web/
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos compartidos
├── seccion1/            # Nosotros
├── seccion2/            # Menú
├── seccion3/            # Galería
└── seccion4/            # Contacto
```

## Flujo de trabajo
- Rama principal: `main`
- Cada sección se desarrolló en su propia rama (`seccion1`, `seccion2`, `seccion3`, `seccion4`)
- Cada rama se integró a `main` mediante Pull Request
